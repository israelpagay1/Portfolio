# Portfolio

A simple logistics portfolio website for Israel Pagay.

## Preview locally

1. Open a terminal in this folder.
2. Run:
   ```bash
   python3 -m http.server 8000
   ```
3. Open your browser at:
   ```
   http://0.0.0.0:8000/
   ```

## Files

- `index.html` — main portfolio page
- `style.css` — page styling
- `script.js` — placeholder for future interactivity

## Notes

- The page uses your provided HTML content.
- Add any image assets under `assets/images/` and documents under `assets/documents/`.
